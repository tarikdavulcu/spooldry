SpoolDry controls a DIY ESP32 filament dryer over Bluetooth LE. Reviewers without the hardware can use the built-in simulated device: Dryer tab -> 'Try the Demo Dryer' (or Settings -> Try the Demo Dryer). The demo speaks the same BLE protocol byte format, runs 60x faster and does not consume free sessions. To test the in-app purchase: Settings -> Get SpoolDry Lifetime (non-consumable, com.tarikdavulcu.spooldry.lifetime). The app has no account, no server and collects no data.
